## Overview

Leap o' Fate is a fully playable retro-style platformer for the Game Boy, built with a classmate
([@panpov](https://github.com/panpov)) in Game Boy assembly, without a game engine. We designed and
iteratively optimized the game logic, movement, and collision detection, then published it online
so anyone can play it in the browser.
